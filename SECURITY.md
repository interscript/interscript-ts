# Security Policy

## Supported Versions

The latest released version of this project receives security fixes.

## Reporting a Vulnerability

Please **do not** open public GitHub issues for security vulnerabilities.

Report privately via one of:

- **GitHub private vulnerability reporting** — Security tab → "Report a vulnerability" (preferred)
- **Email** — ronald.tse@ribose.com

We acknowledge reports within 72 hours. Coordinated disclosure is supported.

## Disclosure

Public disclosure happens after a fix is released, on a timeline agreed with the reporter.
